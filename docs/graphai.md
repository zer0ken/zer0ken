# GraphAI

2025년부터 GraphAI의 AI 엔진팀에 소속해 PoC와 제품 개발을 병행하고 있으며, 사내에서는 개발 문화 개선을 주도하고 있다.

## 주요 작업

### 온디바이스 하이브리드 검색 SDK (EcoVector)

FAISS 클러스터링과 HNSW 기반 벡터 검색, Kiwi 형태소 분석 기반 BM25 검색을 결합한 안드로이드 SDK를 C++17 코어와 Kotlin API(JNI) 구조로 개발했다. 앙상블 검색(RRF/RSF), 토큰 인식 청킹, PDF 텍스트 추출을 지원하며, v0.1.0을 배포하고 릴리즈 자동화와 SDK 가이드 문서 체계를 정비했다.

### AkasicDB 에이전트 스킬

Claude Code와 Codex에서 AkasicDB를 다루는 공식 스킬을 개발했다. 문서 탐색, 인스턴스 셋업, RAG 데이터 레이어 구축 플레이북을 담당했다.

### 온디바이스 RAG PoC

SDK의 벡터·전문 검색 앙상블과 Gemini tool calling을 결합해 기기 내에서 검색 결과를 자연어로 답변하는 RAG 데모 앱을 개발했다. 9단계 파이프라인 기반 검색 성능 벤치마크로 검증했다.

### 사내 개발 환경 도구

벡터 DB 벤치마크 스위트를 결정론적으로 실행하고 결과를 통일 스키마로 아카이브하는 CLI 파이프라인(abench)을 개발해 사내 벤치마크 운영을 자동화했다. 이 밖에 코드 작성 작업을 사내 GPU 서버의 로컬 LLM에 인계하는 오케스트레이션 스킬 등 작업 편의 도구를 만들고 있다.

### 노션 생태계 구축

사내 지식 관리 기반을 노션 위에 구축하는 데 크게 기여했다.
