### xmux

<sub>2026 · Rust</sub>

- 저장소: [zer0ken/xmux](https://github.com/zer0ken/xmux)
- 여러 호스트의 tmux와 psmux 세션을 한 화면에서 탐색하고 전환하는 터미널 멀티플렉서 스위처다.
- 터미널을 소유하는 영속 슈퍼바이저로 동작하며, 좌측 세션 탐색 목록과 우측 터미널 뷰로 이루어진 분할 화면을 제공한다.
- 단일 바이너리로 Windows, macOS, Linux 배포본을 제공한다.
- [homebrew-xmux](https://github.com/zer0ken/homebrew-xmux) 탭과 crates.io를 통해 설치를 지원한다.

### git-pptx

<sub>2026 · JavaScript</sub>

- 저장소: [zer0ken/git-pptx](https://github.com/zer0ken/git-pptx)
- pptx를 슬라이드별 XML과 미리보기 이미지가 담긴 디렉터리로 분해해, Git에서 슬라이드 단위 텍스트 diff를 볼 수 있게 하는 CLI 도구다.
- `decomp`로 분해하고 `comp`로 재조립하며, 변경된 슬라이드만 갱신한다.
- GitHub PR에서 변경 슬라이드가 이미지로 표시된다.
